# AI Content Assistant

An AI-powered content assistant that enables users to summarize YouTube videos and website content, as well as ask questions about the provided sources. By leveraging Large Language Models (LLMs) and LangChain, the application transforms online content into concise summaries and interactive question-answering experiences.

## Features

- **YouTube Video Summarization:** Generate concise summaries from YouTube video content.
- **Website Summarization:** Extract and summarize content from website URLs.
- **Interactive Question Answering:** Ask questions related to the provided video or website content.
- **Context-Aware Responses:** Generate answers based on the source content.
- **URL-Based Content Processing:** Provide a YouTube video link or website URL to get started.
- **LLM-Powered Processing:** Use generative AI to simplify lengthy content and improve information accessibility.

## Technology Stack

- **Programming Language:** Python
- **LLM Framework:** LangChain
- **Language Model:** Groq
- **Core Concepts:** Large Language Models (LLMs), Prompt Engineering, Text Summarization, Context-Aware Question Answering

## How It Works

1. Enter a YouTube video URL or website URL.
2. The application extracts the available content from the source.
3. The LLM generates a concise summary.
4. Ask questions about the source content.
5. Receive AI-generated answers based on the available content.
